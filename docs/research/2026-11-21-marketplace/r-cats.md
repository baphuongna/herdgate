## Kiến trúc cốt lõi (file-level)
- `ios/project.yml` — xcodegen manifest; dep duy nhất Citadel (SSH/NIO, vendored `ThirdParty/Citadel`); quyền Info.plist: NSMicrophoneUsageDescription (dictate pane messages), NSSpeechRecognitionUsageDescription, NSPhotoLibraryUsageDescription → dictation + ảnh là feature cấp OS, không phải web hack.
- `ios/Herdcats/Models/ConnectionBackend.swift` — enum 2 runtime: `tui` (CLI `herdr`) | `core` (API `hc connect`).
- `ios/Herdcats/Networking/HerdrConnection.swift` — actor trung tâm: `ConnectionClientSlot<SSHClient>` + `ConnectionGeneration` (mọi teardown/timeout đều scoped theo generation, task trễ không thể giết attempt mới hơn); host-key TOFU (unknown/changed + fingerprint SHA256).
- `ios/Herdcats/AppModel+Connection.swift` — flow connect: reserve generation → dial → detect backend → check version → session readiness; watchdog 30s.
- `ios/Herdcats/Networking/HerdrConnection+Remote.swift` — wrapper POSIX cho mọi lệnh remote: `remoteCommand()`, `shellSafeArgument()`/`printfOctal()`, `loginPathSetup`, attachment dir, `interpret()`.
- `ios/Herdcats/Networking/PanePersistentShell.swift` — kênh shell POSIX persistent (chi tiết dưới).
- `ios/Herdcats/Networking/PaneLiveInputQueue.swift` — FIFO input có ack, coalescing, không bao giờ replay.
- `ios/Herdcats/Networking/PaneInputCoordinator.swift` — lane độc quyền cho mutation pane (send/escape không chồng nhau).
- `ios/Herdcats/Networking/HerdrConnection+PaneInput.swift` — `paneSubmit` (chính sách per-agent), `coreTypedKeys`, `uploadAttachment` (SFTP).
- `ios/Herdcats/Networking/CoreRPCClient.swift` — JSON-RPC 2.0 NDJSON trên 1 exec channel cho `hc connect`; request id, batch event, cancel.
- `ios/Herdcats/Features/PaneDetail/PaneInputSurfaceModel.swift` — máy trạng thái 3 surface: liveToolbar / voiceRecording / composeDraft.
- `ios/Herdcats/Support/PaneDictation.swift` — SFSpeechRecognizer + SpeechTranscriber (progressive), on-device khi được.
- `ios/Herdcats/Support/PaneImageEncoder.swift` — resize ≤2048px, JPEG.
- `bridge/protocol.json` — protocol bridge Rust `herdcats-bridge` (timeline native): NDJSON stdio, 1 pane/process.
- `ios/docs/pi-conversations.md` — hợp đồng Pi extension (rất liên quan herdgate vì agent là Pi).

## Cơ chế đáng học — chi tiết (code/từ khóa thật + file)
1. Auto-detect runtime, "never switches on its own": `AppModel+Connection.swift` — flag `config.detectsBackend`; sau SSH lên gọi `connection.detectBackends()`; cả hai → chọn TUI ("TUI has every feature"); chỉ core → core. Runtime đã lưu mà thiếu (`HerdrConnection.mayMeanRuntimeIsMissing`) → detect lại cả hai → throw `.runtimeNotInstalled(saved:available:)` (HerdrConnection.swift) — app đề xuất runtime còn lại, lưu thành entry THỨ HAI cho cùng máy, không bao giờ tự đổi. `adoptBackend()` chỉ chạy một lần sau probe.
2. Persistent shell + marker framing: `PanePersistentShell.swift` — 1 SSH exec channel chạy `exec /bin/sh` (non-PTY); mỗi request bọc `command </dev/null\nprintf '\n%s\n' 'HC_<uuid>'` (`PaneShellResponseFrame.command`): stdin-detach để lệnh không nuốt request kế tiếp; decode chỉ khi đủ delimiter `\n<marker>\n` (chunk SSH không corrupt multibyte); limit 8MB; "Never retry a request after writing it". Input và output là 2 shell riêng (`PaneLiveShells`) → read không chặn keystroke. Probe `execute("true")` trước khi bật; lỗi mở → `liveShellUnavailableGeneration` (không thử lại trong generation đó), fallback exec từng lệnh.
3. Input queue có thứ tự: `PaneLiveInputQueue.swift` — bounded 32 batch; enqueue sync trên MainActor; coalesce "Nagle-style" (text+text, keys+keys, cùng session); ack từng event trước khi gửi batch kế (`acknowledgedCount`); lỗi mơ hồ → `state = .needsResync`, drop hết queue, KHÔNG retry; `abandonQueuedInput()` khi đổi pane; session token `PaneLiveInputSession{paneId, generation, streamID}` không tái sử dụng.
4. Ảnh vào terminal = upload + path reference: `HerdrConnection+PaneInput.swift uploadAttachment` → SFTP tạo `$HOME/.cache/herdrcat/attachments/<uuid>.<jpg|png|webp>` mode 0600, `.forceCreate` (không đè); `HerdrConnection+Remote.swift attachmentDirectoryPreparationScript` mkdir từng thành phần `-m 700`, umask 077, fail nếu bất kỳ thành phần là symlink; sau đó chỉ gửi TEXT: `imagePrompt()` = "Please open and inspect this image: <path>\n\n<user msg>" qua `agent prompt`. Không paste binary vào TTY.
5. Dictation drain: `PaneInputSurfaceModel` — `finish()` trả ngay nhưng `isBusy` giữ true tới ~15s chờ transcript cuối; surface đứng im (`isDrainingDictation`) "so an incomplete transcript is never shown or sent"; `sendsWhenDictationDone` chỉ gửi khi user đã bấm Send và không fail; final `onText` (merge draft cũ qua `initialText()`) luôn tới trước khi idle. `PaneDictation.swift`: `requiresOnDeviceRecognition = recognizer?.supportsOnDeviceRecognition == true`; dùng `SpeechTranscriber(preset: .progressiveTranscription)` khi locale hỗ trợ.
6. Shell-safety: `HerdrConnection+Remote.swift shellSafeArgument` — escape toàn bộ byte thành octal `\%03o` cho `printf`, không single-quote/unescaped-double-quote; script nhúng trong `sh -c '...'` an toàn với mọi input người dùng.
7. Non-login SSH PATH: `loginPathSetup` — export thêm `~/.local/bin`, mise shims, `/opt/homebrew/bin`… rồi đọc PATH của login shell qua `$SHELL -lc 'printf "\nHERDRCAT_PATH=%s\n" "$PATH"'` + marker sed; giải quyết "non-interactive SSH có PATH trần".
8. Chính sách submit per-agent (`paneSubmit`): agent → `agent prompt <pane> <text>` (bracketed paste); pane thường → `pane send-text`; Codex đang `working` → type + `Task.sleep 350ms` + `enter` (paste-burst window); Codex blocked → `paneAnswerCodexQuestionUnlocked` đọc `pane read --source visible --lines 60` detect answer field trước khi gõ; Cursor → luôn từ chối nếu không bridge (`CursorPromptPolicy.bridgeMessage`). Core không có raw text: `coreTypedKeys` map ASCII→key names, trả nil với shifted symbols/non-ASCII → hiện "Use Compose to send it" thay vì gửi ký tự sai.
9. Bridge protocol (`bridge/protocol.json`, protocol 1): transport "non-PTY stdio NDJSON; one watched pane per process"; requests: initialize/watch/unwatch/history/content/interaction.respond/model.status/prompt.submit/model.set; events: timeline.snapshot/updated/unavailable, interaction.pending/resolved, model.updated; identity = `["pane_id","terminal_id","agent","native_session_id"]`; reconnect: "No persistent replay cursor… Epoch change or sequence gap requires fresh snapshot". Cài bridge: pinned release + checksum verify → `~/.local/bin/herdcats-bridge`, không sudo, không background service; chỉ stream khi Timeline mở.
10. Pi contract (`ios/docs/pi-conversations.md`): "does not attach RPC to a TUI, resume the session in another process, or inject permission responses"; extension opt-in, validate protocol `1` + session identity; "Failed or uncertain actions are never automatically retried"; "no synthetic 'always allow' scope"; model list từ live Pi catalog, "the phone does not invent a model list".

## Áp vào herdgate (checklist: module/op/file đích, ưu tiên)

## KHÔNG nên học (anti-pattern, platform mismatch, license)
- LICENSE = NOASSERTION (không chuẩn OSS) → KHÔNG copy code/chart; chỉ học thiết kế. Artwork catppuccin/solarized MIT riêng không liên quan.
- Toàn bộ stack Swift/SwiftUI/Citadel/Observation, host-key TOFU Keychain — platform iOS; herdgate là Node/TS + PWA, cơ chế khác (WebCrypto/WebSSH).
- Heuristic scraping màn hình TUI: `pane read --source visible` + detect answer field, sleep 350ms cho Codex — brittle, chỉ tồn tại vì app từ chối can thiệp không-verify; herdgate có receipts/pane events chính xác, đừng port timing hack.
- Marker-over-shell là workaround cho ràng buộc "stock SSH, no helper" — herdgate gate đã có relay persistent riêng; chỉ áp cho Mobile TUI SSH trực tiếp, không thay relay.
- Dừng poll terminal khi Timeline hiện (tiết kiệm pin iOS) — PWA dùng Page Visibility API theo cách riêng, đừng copy nguyên logic surface.
- Bridge cài binary pinned-release về máy user — herdgate self-host gate nên cập nhật qua pipeline hiện có, không cơ chế tự download GitHub release trong app.
