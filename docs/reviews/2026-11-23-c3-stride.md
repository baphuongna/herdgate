# C3 — Security review STRIDE: surface op mới (v0.9.38→v0.9.45)

Ngày: 2026-11-23 · Vòng: DEV-LOOP C3 · Phương pháp: STRIDE, code-before-checklist
Pass đọc code: `plugin/server/index.mjs` (toàn bộ dispatch op thiết bị), `plugin/server/common.mjs` (herdrPanes/herdrRead), `src/cloud/gateway.ts` (hello/hostInfo, /v1/devices), `src/cloud/stores.ts` (setRoomHostInfo), `plugin/mirror/*` (pair/stream/watch).

Mô hình tin cậy: device chân thật = do owner pair (read/act), owner token chỉ trong systemd/PWA; gate public (cloudflare); publisher nghe mọi frame từ device đã pair trong room.

## Findings (xếp theo приоритет)

### F1 — MEDIUM · DoS (tự sát socket publisher) · `fleet.detail` + `term.list` trả `panes` KHÔNG giới hạn
- **Đ_where**: `plugin/server/index.mjs` — fleet.detail (~:925 trả `panes` thô từ herdrPanes), term.list (~:886 cùng shape).
- **Exploit路径**: máy có ~2.500+ pane (script tạo tab, herdr power user) → JSON reply > 256KiB → gate đóng socket publisher vì `maxPayload` → publisher reconnect loop → **cả room chết**. Đúng lớp bug Part 7 (file.read 262KB từng giết publisher thật).
- Devices `read` cũng gây được (không cần act) — nhưng trả giá tự thân (chết room của chính mình); vẫn phải sửa vì một tab storm vô tình cũng trigger.
- **Fix**: cap 200 pane/lan + trường `panesCapped: true` + chuỗi đã trim sẵn ở herdrPanes (đã có) → reply luôn nhỏ. Test: stub 300 pane → 200 + flag.

### F2 — LOW · Info disclosure · stderr git dòng đầu echoed về device
- **Where**: diff.get / review.* / file.tree error path (`stderr.split("\n")[0]`).
- **Exploit**: ref/path hợp lệ nhưng git lỗi → message có thể lộ path hệ thống local ("fatal: /home/..."). Device đã là người được owner tin (read) nên giá trị lộ thấp. **Chấp nhận, ghi nhận** — không sửa vòng này.

### F3 — LOW · DoS · hostInfo ghi đĩa mỗi hello nếu đổi liên tục
- **Where**: `src/cloud/stores.ts` setRoomHostInfo.
- Đã có mitigation: bỏ qua write khi giá trị không đổi và <60s. Tấn công cần room token hợp lệ (= chính publisher tin cậy) → self-DoS. **Ghi nhận, không sửa.**

### F4 — INFO · functional gap (không phải lỗ hổng) · `pane.focus` regex `w\d+:p\d+`
- Pane id thật có dạng `wG:p1` (laptop) — regex chỉ nhận `w<digits>` → không focus được. Backlog C4.

## Đã kiểm, sạch (dẫn chứng đối chiếu)

- **file.read**: thứ tự chặn đúng (exist → realpath-under-repo → tracked-only), no `/`-đầu, no `..`, no NUL, ≤255; symlink trong repo trỏ ra ngoài bị realpath chặn; wire-budget shrink loop có.
- **term.send/term.keys**: act gate trước mọi thứ; argv array không shell; text 1..4096; keys ≤8, charset chặt; log chỉ độ dài text (không log keystroke — mật khẩu gõ qua mirror không vào journal).
- **review.send**: act + HERDGATE_PI_WORKER gate; comment validate từng field; queue cap; `principal: device:<id>` = audit trail; prompt đi worker queue có sẵn.
- **fleet.detail agents**: cap 50 + mọi chuỗi slice — sạch (chỉ `panes` sót = F1).
- **hostInfo (C1)**: 4 keys tối đa, chuỗi ≤64, invalid bỏ cả khối, no-info → honest absence; /v1/devices account-gated.
- **mirror**: config 0600, secret masked ở status, pair cần account token + host approve, typing cần act.
- **term.read**: lines kẹp 10..120, target charset chặt, throttle 1/s, fallback pane-read chỉ khi agent_not_found.
