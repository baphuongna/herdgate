## Tính năng

`sdd.mjs run <name> <brief.md> [--cwd DIR] [--model M] [--timeout MS]`

1. **Lock ép 1 subagent/lúc**: `<spawnBase>/sdd.lock` JSON `{pid,name,at}`;
   pid còn sống → refuse exit 1 (tên kẻ giữ + lệnh cứu); pid chết → mồi cũ,
   ghi đè (tự lành). Nhả trong `finally`.
2. **start**: `task.mjs start <name> <brief> --tab --cwd <cwd> -- --model
   <M|zai/glm-5.3-flash> --thinking max --tools read` — read-only ÉP BẰNG
   CẤU HÌNH (bài học wave 3), `--tools` override được cho vai khác sau này.
3. **wait**: `herdr agent wait <pane> --until idle --until done --timeout
   <MS|600000>` qua `HERDR_BIN_PATH` — không poll (bài học wave 3).
4. **answer**: `findSpawn` → `findReceipt(base, id).sessionId` → tìm
   `*_<sessionId>.jsonl` dưới `~/.pi/agent/sessions/*/` → dòng
   `role:"assistant"` CUỐI có content block `type:"text"` → in nguyên văn
   ra stdout (đây là findings controller đọc). Thiếu receipt/sessionId/file →
   exit 2 kèm chỉ đường đọc tay (trung thực, không bịa).
5. **close**: `task.mjs close <name>` (giữ guard từ chối đóng agent working);
   close hỏng → answer vẫn in (đã đọc) + cảnh báo + exit 5. Lock luôn nhả.

Export hàm thuần để test: `lastAssistantText(lines)`, `resolveSessionFile`,
`acquireLock`/`releaseLock`. Bằng chứng argv = **e2e sandbox kiểu
pi-task.test.ts**: herdr stub (HERDR_BIN_PATH) ghi mọi call vào STUB_LOG,
registry/receipt trong tmp — task.mjs chạy THẬT trong sandbox, không đụng hệ
thật (controller đọc STUB_LOG để assert).

## Test (đỏ trước) — `test/sdd-helper.test.ts`

- **T1**: `run` gọi đúng chuỗi argv qua 2 seam: start có `--tools read`
  (không có flag nào lật được) + model mặc định; wait có `--until idle
  --until done --timeout`; close gọi sau answer-fail (dọn pane) — riêng nhánh
  wait-timeout T1 chỉ khẳng định close ĐƯỢC THỬ (F7).
- **T2**: lock sống (pid = PID tiến trình `sleep` con thật) → exit 1, KHÔNG
  spawn; lock mồi (pid chết) → chạy tiếp.
- **T3**: `lastAssistantText` — fixture jsonl thật shape: lấy dòng assistant
  cuối có text (bỏ thinking/toolResult); text = join các block `type:"text"`
  KHÔNG rỗng; chuỗi chỉ có block rỗng → null (F10).
- **T4**: wait JSON stdout có `agent_session.value` → dùng thẳng (F4); thiếu
  → fallback glob chọn mtime mới nhất; không thấy → null.
- **T5**: answer thiếu session file → exit 2, thông điệp có đường đọc tay,
  close vẫn được gọi.
- **T6**: idle race — wait trả trong cửa sổ chưa-working; settle loop chờ
  text + không-working (stub seq idle,working,idle).
- **T7**: wait fail → exit 4 + close attempted + rescue line.
- **T8**: budget hết khi agent còn working → exit 4, KHÔNG deliver text
  giữa chừng (bug round 2), lock nhả.
