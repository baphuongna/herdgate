# Spec — Trang quản trị gate `/admin` (→ 0.14.0)

Ngày: 2026-11-25 · Nguồn: yêu cầu chủ sở hữu ("làm thành 1 trang web quản trị hoàn chỉnh") ·
Chính sách release: 2b(b) — bump vì user yêu cầu tính năng.

## Mục tiêu người dùng

Từ trình duyệt (máy tính, cũng dùng được trên điện thoại): chủ sở hữu **nhìn toàn bộ gate và làm
mọi thao tác vòng đời** — duyệt máy, đổi tên, gỡ máy cũ; xem/thu hồi thiết bị, thu quyền act, quản
lý key SSH; xem mã ghép đang chờ và duyệt; đọc sự kiện gần đây — **không cần `curl` hay SSH vào
máy chủ**. PWA hiện tại (`/`) vẫn là app thao tác trên máy (terminal, file, review); trang này là
console của chính cái gate.

## Ràng buộc giữ nguyên

- Một nguồn, một origin với PWA và WS; CSP hiện hành không đổi (`script-src 'self'`, không inline).
- Mọi chuỗi từ mạng vẽ bằng `textContent`; không `innerHTML`/`insertAdjacentHTML`.
- Token chủ sở hữu chỉ vào header `Authorization` tới `/v1/…` cùng origin; không bao giờ vào URL.
- Không in bí mật: token, secret thiết bị, key riêng. Key SSH chỉ hiện fingerprint.
- **Cấp `act` vẫn do host duyệt lúc ghép** — trang quản trị chỉ *hạ* quyền (act → read), không nâng.
- Gate không biết và không làm việc của systemd: khởi động lại, backup, nâng cấp vẫn qua CLI/runbook.
- Phạm vi "cửa hẹp": một tài khoản chủ sở hữu; không quản lý người dùng, không chat, không terminal.

## F1 — `GET /v1/admin/overview` (Bearer token chủ sở hữu; rate limit như `/v1/devices`)

```json
{ "gate": { "version", "startedAt", "uptimeSec", "ssh": { "enabled", "publicPort" }, "push", "web" },
  "counts": { "rooms", "devices", "agentsOnline", "devicesLive", "pendingCodes" },
  "rooms": [ { "id", "name", "created", "host": { "name", "version" } | null, "connected", "devices": { "total", "live" } } ],
  "devices": [ { "id", "name", "roomId", "roomName", "scope", "legs", "lastSeen", "keys", "push", "payload", "created" } ],
  "pairing": { "pending": [ { "code", "hostName", "ageSec", "expiresIn" } ] } }
```

Một request thay cho N lần `GET /v1/devices?room=`. `pairing.pending[].code` chỉ tới chủ sở hữu
(vì cần nó để duyệt). Thiếu token → 401.

## F2 — `GET /v1/admin/events?after=<seq>` — vòng nhật ký trong RAM

- 300 dòng gần nhất của chính `log()` của gate: `{ seq, at, line, kind }`; `kind` phân loại theo
  tiền tố: `pair` (room … approved), `device` (device … connected/disconnected/pair), `agent`
  (agent … connected/disconnected), `ssh` (ssh: …), `gate` (listening/shutting down), `other`.
- `after` trả phần từ `seq > after`; không persist, mất khi gate khởi động lại (đúng ý: journal
  hệ thống vẫn là nguồn thật).
- Log của gate hiện không chứa bí mật (đã rà: chỉ id/tên/IP) — giữ nguyên khi thêm dòng mới.

## F3 — Thao tác (Bearer token, POST JSON)

| Route | Body | Hiệu lực | Lỗi |
|---|---|---|---|
| `POST /v1/room/rename` | `{room, name}` | tên 1–64 ký tự, không ký tự điều khiển | 400 tên, 404 room |
| `POST /v1/room/remove` | `{room}` | gỡ room **và** thiết bị của nó; ngắt agent; xoá stream buffer | 404 |
| `POST /v1/device/rename` | `{device, name}` | như trên | 400, 404 |
| `POST /v1/device/scope` | `{device, scope:"read"}` | hạ scope; đá WS của thiết bị (close 4003 `scope changed`) và mọi phiên SSH đang sống; key SSH giữ nguyên | 422 nếu `scope:"act"` — "act is granted by the host at pairing" |

Mỗi thao tác ghi một dòng log → hiện ở F2. Revoke/sshkey/push/approve dùng route có sẵn.

**F3b — Agent dừng quay số khi bị gỡ.** Gate đóng socket agent bằng `4001 "unknown room token"`.
Hiện agent bỏ qua mã close và redial mãi (lùi 1–30 s) bằng token đã chết: với IP công cộng, 5 lần
thất bại là `strike` chặn cả IP đó 60 s — điện thoại cùng WiFi với laptop bị từ chối oan. Sửa: agent
gặp đúng cặp mã/lý do đó thì ghi một dòng rõ ràng ("không còn ghép — chạy `herdgate pair` lại") và
**không** lên lịch redial; getter `unpaired` để host/test đọc.

**F3c — `POST /v1/agent/deny {code}`** (chủ sở hữu): bỏ một mã đang chờ (`AgentCodes.deny`).

## F4 — Static: `/admin` → `admin.html`

`resolveStatic` nhận `aliases`; gateway truyền `{ "/admin": "/admin.html" }`. File mới:
`admin.html`, `admin.css`, `admin.js`, `admin-model.js` — cùng chính sách cache/CSP với shell.

## F5 — Service worker không chạm `/admin`

Hiện SW cache **mọi** điều hướng vào kho `/` và cache-first mọi asset same-origin → trang admin sẽ
bị phục vụ nhầm offline và `admin.js` bị giữ bản cũ sau deploy. Sửa: SW chỉ xử lý điều hướng
`pathname === "/"` và asset đúng trong `SHELL`; mọi thứ khác để trình duyệt tự đi mạng.

## F6 — UI (vanilla, không phụ thuộc, desktop-first, co được về điện thoại)

- Đăng nhập bằng token (ô mật khẩu), lưu `localStorage["herdgate.token"]` — chung khoá với PWA để
  không phải gõ lại; nút Đăng xuất xoá khoá này. 401 → về màn đăng nhập.
- **Tổng quan**: thẻ gate (phiên bản, uptime, SSH-leg, push, web), ô đếm (máy, thiết bị, máy online,
  thiết bị đang nối, mã chờ), danh sách mã ghép đang chờ + nút Duyệt.
- **Máy**: bảng (tên, host + phiên bản, publisher, thiết bị sống/tổng) → đổi tên, gỡ (xác nhận,
  nêu số thiết bị bị gỡ kèm).
- **Thiết bị**: bảng toàn fleet (tên, máy, scope, chân web/ssh, thấy lần cuối, key, push) + ô lọc;
  hành động: đổi tên, thu quyền act (xác nhận), thu hồi (xác nhận), key SSH (fingerprint + xoá +
  thêm bằng pubkey dán vào), tắt push.
- **Ghép nối**: mã đang chờ + ô nhập mã để duyệt tay.
- **Sự kiện**: đuôi log tăng dần theo `after`, nút tạm dừng/xoá màn hình.
- Tự làm mới mỗi 4 s; **dừng khi tab ẩn** (`visibilitychange`).
- `admin-model.js` là module thuần (không DOM) để test được trong Node: dẫn xuất bảng/ô đếm, định
  dạng tuổi, phân loại sự kiện, kiểm tên, lọc thiết bị. `admin.js` chỉ làm DOM + fetch.
- PWA: thêm một liên kết "Trang quản trị" trong hộp Settings (không đụng logic khác).

## Non-goals (ghi rõ để không trôi)

Cấp act từ trang quản trị; khởi động lại/backup/nâng cấp gate từ trang; nhiều tài khoản; terminal/
file/review (PWA đã có); real-time (polling 4 s đủ cho một chủ); đổi token chủ sở hữu.

## Test (NO TEST = NO MERGE)

- `test/admin-api.test.ts` (cloud trong tiến trình + agent thật + DeviceSock như `devices.test.ts`):
  401 không token; overview đúng hình + đếm; mã chờ liệt kê có code; events: vòng giới hạn 300,
  `after` trả phần mới; rename hợp lệ/ký tự điều khiển; remove cascades (thiết bị mất, socket thiết
  bị đóng, agent nhận close); scope: hạ được + WS bị đóng 4003 + phiên SSH bị đá; nâng act → 422.
- `test/web-admin.test.ts`: alias `/admin`; file được phục vụ với CSP; `admin.js`/`admin-model.js`
  không `innerHTML`, token không vào URL, chỉ gọi `/v1/`; SW không xử lý `/admin*`; `index.html`
  có liên kết; unit test `admin-model.js`.
- Mutation: mỗi rào chính (422 nâng act, 401, giới hạn 300, SW bỏ qua `/admin`) được phá thử một
  lần và phải thấy test đỏ.
